\paragraph{Q: What does this file do?}
\textbf{A:} This is a preprocessing script that merges raw KuaiRec CSVs, engineers/normalizes labels and durations, builds vocabularies for sparse and sequence features, constructs a feature schema, creates train/test splits, and writes the final pickle used by training.

\paragraph{Q: Why is the output schema (description) important?}
\textbf{A:} All models and the dataloader depend on the description list to decide feature types and vocab sizes. If it is wrong, embeddings and tensors will not line up.

\paragraph{Q: Why does this script also generate D2Q artifacts?}
\textbf{A:} D2Q needs a duration bucket index and per-bucket play-time quantiles to map raw labels to a quantile target and back. The script produces these CSVs for reproducible D2Q training.
