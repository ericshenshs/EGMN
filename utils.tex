\paragraph{Q: What does this file provide?}
\textbf{A:} This file provides shared metrics (MAE, XAUC, KL) and TPM-specific encoding/decoding helpers for tree-based bucket prediction.

\paragraph{Q: Why does the repo use XAUC for a regression-like task?}
\textbf{A:} XAUC measures whether larger predictions correspond to larger labels (a ranking-consistency signal). It complements MAE (absolute error).
