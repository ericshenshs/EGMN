\section{Repository overview (Q\&A)}

\subsection{Q: What is this repository?}
\noindent\textbf{A:} This is a PyTorch research codebase for \textbf{video watch-time prediction}, implementing the EGMN paper and several baselines, with preprocessing and experiments primarily for the public \href{https://kuairec.com/}{KuaiRec} dataset.

\subsection{Q: What are the main folders and entrypoints?}
\noindent\textbf{A:} Models live in \lstinline|model/|, dataset loading is in \lstinline|dataloader/|, KuaiRec preprocessing is in \lstinline|dataset/kuairec/|, runnable experiments are in \lstinline|run_*.py|, and shared metrics/utilities are in \lstinline|utils.py|.

\subsection{Q: What metrics are reported by the run scripts?}
\noindent\textbf{A:} The run scripts evaluate on \lstinline|test| and report \textbf{MAE} (absolute error), \textbf{XAUC} (ordering agreement after sorting by predicted score), and \textbf{KL} divergence between binned empirical distributions.

\subsection{Q: How do you run EGMN and baselines (example commands)?}
\noindent\textbf{A:}
\begin{lstlisting}[language=bash]
# Train + evaluate the proposed EGMN model on KuaiRec
python run_egmn.py --dataset_name kuairec --device cuda:0

# Baselines (examples)
python run_cread.py --dataset_name kuairec
python run_d2q.py --dataset_name kuairec
\end{lstlisting}
