\section{Workflow: dataset preprocessing and running experiments}

\subsection{Dataset preprocessing (KuaiRec)}
The KuaiRec raw data must be preprocessed before training. The provided script in \lstinline|dataset/kuairec/kuairec_process.py|:
\begin{itemize}[leftmargin=*]
  \item merges multiple KuaiRec feature CSVs into a single table,
  \item builds vocabularies for sparse/sequence features,
  \item constructs a feature \lstinline|description| schema used by models and dataloaders,
  \item splits into \lstinline|train|/\lstinline|test|,
  \item writes \lstinline|kuairec_data.pkl| containing the processed data and schema.
\end{itemize}

It also produces duration buckets and per-bucket play-time quantiles used by the D2Q baseline.

\subsection{Code snippet: preprocessing outputs (D2Q support)}
\begin{lstlisting}[language=Python]
# dataset/kuairec/kuairec_process.py (illustrative excerpt)
n_bins = 50
df["duration_bucket"], bins = pd.qcut(df["duration"], q=n_bins, labels=False,
                                      retbins=True, duplicates="drop")
desc.append(("duration_bucket", len(bins) - 1, "spr"))

# Per-bucket play-time quantiles for D2Q mapping
quantile_num = 100
quantiles = np.linspace(0, 1, quantile_num + 1)
quantile_df = (df_train.groupby("duration_bucket")["play_time"]
               .quantile(quantiles).reset_index())
quantile_df.pivot(index="duration_bucket", columns="quantile",
                  values="play_time").to_csv(
    "d2q_duration_bucket_playtime_quantiles.csv"
)
\end{lstlisting}

\subsection{Training / evaluation entrypoints}
Each method has a \lstinline|run_*.py| entrypoint. Typical usage is:
\begin{itemize}[leftmargin=*]
  \item \lstinline|python run_egmn.py --dataset_name kuairec|
  \item \lstinline|python run_cread.py --dataset_name kuairec|
  \item \lstinline|python run_d2q.py --dataset_name kuairec|
\end{itemize}

These scripts:
\begin{itemize}[leftmargin=*]
  \item load \lstinline|./dataset/kuairec/kuairec_data.pkl| through \lstinline|dataloader/kuairec.py|,
  \item train for a fixed number of epochs,
  \item evaluate on the test set,
  \item print MAE, XAUC, and KL divergence.
\end{itemize}

\subsection{Code snippet: EGMN training loop structure}
\begin{lstlisting}[language=Python]
# run_egmn.py (illustrative excerpt)
for epoch in range(1, args.epoch + 1):
    for features, label in dataloaders["train"]:
        pi, lambda_, mu, sigma = model(features)
        nll, reg, ent = model.loss(label.float(), pi, lambda_, mu, sigma,
                                   features["duration"].view(-1, 1))
        loss = nll + args.alpha * ent + args.beta * reg
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
\end{lstlisting}
